FIRE CONTROL — LOCAL HLL ARTILLERY MAP

Open index.html in a modern browser. No installation or server is required. Map images are included; the optional web fonts require internet and fall back to system fonts.

Choose a battlefield, side, gun profile and HQ gun. Click the map to set a target. Click a numbered marker to select a gun. To place an alternative gun, choose Place custom gun and click its position. Use the zoom buttons and scroll the map when zoomed. Enter a distance in Quick Calculator for a manual firing solution.

The 20 maps, map dimensions, HQ coordinates and ballistic tables come from l1tku's HLL Artillery Map Calculator v1.4.3 / Update 21: https://github.com/l1tku/hll-arty-map-calculator . The included REFERENCE-LICENSE.txt contains its code license and asset exclusions. Tactical map images are game assets and belong to their respective owners. This is an unofficial non-commercial tool.

The map transform follows the reference implementation: Unreal game coordinates use 100 units per meter, x increases east, and y increases north. Distance is Euclidean; bearing is clockwise from north. Elevation linearly interpolates between the reference's 100 m table entries and rounds to the nearest whole MIL, within 100–1600 m. Calculations are estimates: map clicking, game dispersion, and data changes can affect impact. Fixed positions are community-provided and have not been independently surveyed in-game. Verify the selected gun profile against the weapon in your match, particularly for custom positions. Self-propelled artillery terrain corrections are not included.

Additional comparison: https://hellletloose.info/calculators . Its British approximation differs slightly from the reference's table; this app consistently uses the reference table rather than mixing formulas.
